## 📌 Опис принципу LSP
**Liskov Substitution Principle** — це принцип, який вимагає, щоб класи-нащадки могли використовуватися замість своїх базових класів, не порушуючи логіку програми. Якщо підклас змінює очікувану поведінку (наприклад, видаляє функціонал або додає критичні обмеження), цей принцип порушується.

## ❌ Приклад 1: Птах та Страус (Проблема нелітаючих птахів)

### Порушення LSP
Клієнт очікує, що будь-який птах може літати. Страус ламає цю логіку.

```csharp
public class Bird {
    public virtual void Fly() => Console.WriteLine("Птах летить");
}

public class Ostrich : Bird {
    public override void Fly() {
        // Порушення: викидання виключення там, де очікується дія
        throw new NotSupportedException("Страуси не вміють літати!");
    }
}
